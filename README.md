# NEXVARY RealEstate AI OS

AI-first, white-label operating system for real-estate companies.

> Status: active development. The platform is being built as a multi-tenant system with a structured source of truth for inventory/pricing and RAG for documents and knowledge.

## Core principles

- **Structured truth first:** prices, unit availability, reservations, installments and commissions come from transactional data, not model memory.
- **RAG for knowledge:** brochures, policies, contracts and FAQs are retrieved from indexed documents.
- **Multi-tenant by design:** tenant isolation, branding and role-based access are first-class.
- **Human handoff:** AI assists sales/support and escalates when confidence or policy requires it.
- **Auditability:** important actions are logged and attributable.
- **Arabic-first UX:** proper RTL with English support.

Development happens through reviewed feature branches and CI gates.
