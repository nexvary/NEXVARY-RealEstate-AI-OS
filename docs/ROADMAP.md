# Product roadmap

## Foundation — current
- Multi-tenant data model
- API health and core CRM endpoints
- Unit search constrained to available inventory
- Deterministic lead scoring
- Arabic/English responsive dashboard shell
- Docker development services
- CI release gate

## CRM & inventory
- Authentication + RBAC
- Tenant isolation/RLS
- Projects, buildings, units and payment plans
- Lead timeline, assignments, tasks and notes
- Appointments and follow-up engine
- Importers for CSV/XLSX and controlled Google Sheets sync

## AI + RAG
- Document ingestion and pgvector
- Citation-aware retrieval
- Sales Agent with tool calls into structured inventory
- Customer Service Agent
- Human handoff and confidence thresholds
- Conversation memory scoped by tenant/customer

## Omnichannel
- WhatsApp Business Platform
- Website chat
- Messenger/Instagram
- Telegram
- Unified inbox and SLA metrics

## Transactions
- Reservations
- Contract workflow
- Installment schedules
- Collections reminders
- Broker commissions
- Finance/accounting integrations

## Marketing Studio
- Listing copy and campaign variants
- Evidence-bound property descriptions
- Arabic voiceover/subtitles
- Vertical video assembly using supplied media
- Approval workflow before publishing

## White label & operations
- Branding panel
- Tenant domains
- Plans/limits
- Audit export
- Backups/restore
- Observability and incident runbooks
